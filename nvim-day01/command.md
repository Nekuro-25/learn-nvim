# Command — Day 01

## Simpan dan keluar

- `:w` — simpan
- `:q` — keluar
- `:wq` — simpan lalu keluar
- `:q!` — keluar tanpa simpan

## Config Ice Night

- `<leader>w` — simpan. Leader = `Space`, jadi tekan `Space` lalu `w`.
- `<leader>q` — keluar.
- `<leader>w` **bukan** window. Window memakai `Ctrl+w` lalu `h/j/k/l`.

## Cek masalah

- `:messages` — lihat pesan/error terakhir.
