There's a lot of navigation move in nvim (you can use it in normal mode)

First is h, j, k, l (for move 1 character)
H for moving left 1 character
j for moving down 1 line
k for moving up 1 line
l for moving right 1 character

Second is w, b, e
w stand for word, moving forward and place cursor at the start of the word
b stand for back, moving backward and place cursor at the start of the word
e stand for end, moving forward and place cursor at the end of the word

Thir is:
0 for moving cursor to the start of current line
^ for moving cursor to the first character on current line
$ for moving cursor to the end of current line
gg for moving cursor to the start of the document
G for moving the cursor to the end of the document

# Navigation — Day 01

## Gerak dasar

- `h` — kiri
- `j` — bawah
- `k` — atas
- `l` — kanan

## Gerak per kata

- `w` — awal kata berikutnya
- `b` — awal kata sebelumnya
- `e` — akhir kata

## Gerak per baris / file

- `0` — awal baris
- `^` — karakter pertama non-spasi
- `$` — akhir baris
- `gg` — baris paling atas
- `G` — baris paling bawah
