# Navigation in Neovim

Use these in Normal mode.

## Basic movement — 1 character

- `h` — move left one character.
- `j` — move down one line.
- `k` — move up one line.
- `l` — move right one character.

## Word movement

- `w` — word: move forward and place the cursor at the start of the next word.
- `b` — back: move backward and place the cursor at the start of the previous word.
- `e` — end: move forward and place the cursor at the end of the current word.

## Line and document movement

- `0` — move the cursor to the start of the current line.
- `^` — move the cursor to the first non-blank character of the current line.
- `$` — move the cursor to the end of the current line.
- `gg` — move the cursor to the start of the document.
- `G` — move the cursor to the end of the document.

## Practice rule

During the core drill: no mouse, no arrow keys.
